# Vitalis Healthcare App

Vitalis is a next-generation healthcare intelligence platform designed to provide personalized insights and proactive wellness management.

## Features

- **Proactive Monitoring**: AI-driven detection of health marker shifts.
- **Deep Analytics**: Visualization of health journeys with industry-leading data representation.
- **Privacy First**: End-to-end encryption for all sensitive health data.
- **Real-time Vitals**: Live tracking of heart rate, oxygen saturation, and more.

## Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Design**: Premium dark-mode aesthetic with glassmorphism and modern typography (Inter, Outfit).
- **Deployment**: Ready for static hosting.

## Project Structure

- `index.html`: Main landing page structure.
- `style.css`: Modern styling and responsive design.
- `main.js`: Interactivity and animation logic.
